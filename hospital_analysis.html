1. பயன்படுத்தப்பட்ட அல்காரிதம்கள் (Algorithms Used)

இந்த திட்டத்தில் சிக்கலான அல்காரிதம்கள் இல்லை. எளிய Rule-Based Logic மட்டுமே உபயோகப்படுத்தப்பட்டுள்ளது.

  • AutoFlowEngine.js: தானியங்கி நோயாளி ஓட்டு (Patient Flow) மேலாண்மை.
    • Waiting > 30 நிமிடங்கள் → Emergency
    • Consultation > 45 நிமிடங்கள் → Lab/Pharmacy/Billing
    • Lab/Pharma > 120 நிமிடங்கள் → Checked Out
  • PredictWaitTime: கடைசி 1 நாள் சராசரி கணிப்பு (AVG(TIMESTAMPDIFF))
  • Cron Job: 5 நிமிடங்கள் ஒருமுறை சோதனை

ஏன் இந்த அல்காரிதம்கள்? அருகம்பதிவு ஓட்டு - Queue/ State Machine போல. BFS/Graph தேவையில்லை, SQL Queries + Simple IF போதும்.
